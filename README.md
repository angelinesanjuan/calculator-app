# Calcura — DCIT 26 Laboratory 1

A fully functional responsive calculator website built with React, Tailwind CSS, and Vite.

## Requirements covered

- React components and React state
- Tailwind CSS layout and responsive styling
- Calculator display
- Number buttons 0–9
- +, −, ×, ÷ operators
- Clear/reset (AC)
- Equals button
- Dynamic calculations
- Decimal values
- Keyboard support
- Division-by-zero error handling
- Responsive design
- User Guide / Instructions section
- Button interaction effects

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build for deployment

```bash
npm run build
```

The production files will be in `dist/`.

## Deploy to Vercel

1. Push this project to GitHub.
2. Import the repository into Vercel.
3. Framework preset: Vite.
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.

The final link will look similar to:

`https://your-project-name.vercel.app`
